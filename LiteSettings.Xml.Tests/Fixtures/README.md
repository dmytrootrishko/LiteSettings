# Fixtures

`settings.en-US.xml` and `settings.uk-UA.xml` were written by the original ProgramSettings code
(the sources in `..\Legacy`) from `SampleData.Create()`, with the current culture set to en-US and uk-UA.
They are stored with a UTF-8 byte order mark and Windows line endings, the way ProgramSettings wrote them on Windows.

They are frozen samples of the old format. Do not regenerate them with LiteSettings.
